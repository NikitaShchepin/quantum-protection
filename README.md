# quantum-protection
Проект создал 12-летний разработчик (идея моя, код с AI).  Программа решает проблему деления на ноль при испарении черной дыры (M = 0).  1. Если M > 0: применяется фильтр (1/M) - (1/(M + M²)), сглаживающий температуру. 2. Если M &lt;= 0: код предотвращает ошибку и фиксирует объект как стабильный квантовый кристалл с температурой 1.00.
